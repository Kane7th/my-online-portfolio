Uptwn Ldn Clothing Website

2026

  • Guest cart with server sync and checkout flow
  • Admin catalogue API through to production deploy

Full-stack e-commerce site for Uptwn Ldn, a London streetwear label (Beyond The Noise). React and Vite SPA, React Router, CSS Modules, Bebas Neue / Inter typography. Hosted on Ubuntu with nginx.

About Me

Who I Am

I'm Kane Kabena, a full-stack developer in London. I ship production software: Next.js and TypeScript for product UIs, Python / Flask for APIs, and PostgreSQL for data that has to stay correct under load.

What I Build

My flagship is MySmartRental 2.0 (staging live today). I have also shipped e-commerce (Uptwn Ldn), SokoCredit (M-Pesa, Twilio, RBAC), and property SaaS v1. I own the stack from schema design to deployed nginx.

Beyond Web Dev

I also build for FiveM and RedM: custom Lua scripts, economy tuning, and server tooling. Running a roleplay server and selling scripts on Tebex taught me how web backends, databases, and in-game logic fit together.

My Approach

I keep learning as tools change. On each project I aim for clear REST APIs, sensible database queries, and docs or tests where they help the next person. I solve payments, full-stack delivery, real-time features, and e-commerce integrations end to end.
